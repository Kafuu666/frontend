Belajar Float & Clear

1. Float

Gambar

Float digunakan untuk membuat elemen berpindah ke kiri atau ke kanan sehingga teks dapat mengelilinginya. Sebelum Flexbox dan CSS Grid populer, teknik ini sering digunakan untuk membuat layout website.

Pada contoh ini, kotak hijau berada di sebelah kiri, sedangkan paragraf mengalir mengikuti sisi kanan gambar.

Elemen ini menggunakan clear: both; sehingga tampil di bawah elemen yang di-float.

2. Multi Column Layout

CSS juga menyediakan fitur Multi-column Layout yang memungkinkan sebuah teks dibagi menjadi beberapa kolom seperti pada koran atau majalah. Dengan properti columns, browser akan secara otomatis membagi isi menjadi beberapa kolom. Properti column-gap digunakan untuk mengatur jarak antar kolom, sedangkan column-rule digunakan untuk memberikan garis pemisah antar kolom sehingga tampilannya lebih rapi dan mudah dibaca.

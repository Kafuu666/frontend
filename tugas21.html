Pengenalan CSS

1. Inline CSS

Paragraf ini menggunakan Inline CSS. Style ditulis langsung pada atribut style.

2. Internal CSS

Judul dan paragraf ini menggunakan Internal CSS yang ditulis di dalam tag <style>.

3. External CSS

Contoh ini sebenarnya menggunakan class yang biasanya ditulis pada file style.css. Namun, pada latihan ini CSS digabungkan ke dalam tag <style>.
